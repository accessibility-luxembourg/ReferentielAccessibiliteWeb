---
title: Chaque outil d’édition qui crée du contenu diffusé dans une application mobile permet-il de définir les informations d’accessibilité nécessaires pour créer un contenu conforme au [RAAM](../raam2/index.html) ?
---
1. Repérer dans l’outil les fonctionnalités d’édition (par exemple, un éditeur de texte, mais cela peut être une médiathèque ou toute autre interface qui permet de saisir du texte ou définir des propriétés) qui permettent de créer du contenu diffusé dans une application mobile.
2. Vérifier qu’il est possible de définir les informations d’accessibilité nécessaires pour rendre le contenu conforme aux critères du RAAM. Par exemple : 
	- définir le nom accessible d’une image depuis l’éditeur de texte ou une médiathèque ;
	- définir le nom accessible d’un lien ;
	- etc.
3. Si c’est le cas, **le test est validé**.
