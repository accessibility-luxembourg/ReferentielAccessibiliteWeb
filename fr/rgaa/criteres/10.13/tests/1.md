---
title: Chaque page web vérifie-t-elle ces conditions ? 
steps:
  - La page web ne bloque pas l’application des préférences de l’utilisateur, pour les fonctionnalités d’accessibilité documentées par l’agent utilisateur.
  -  La page ne surcharge pas explicitement les préférences de l’utilisateur, pour les fonctionnalités d’accessibilité documentées par l’agent utilisateur.
---

1. Rechercher les fonctionnalités d’accessibilité documentées par l’agent utilisateur : 
	- dans une documentation dédiée ; 
	- ou depuis la liste des paramètres d’accessibilité personnalisables, directement dans le navigateur. Par exemple, depuis Firefox, accéder au menu de l’application, activer le menu « <em>Paramètres</em> » puis afficher la page « <em>Accessibilité</em> ». On trouve parmi les paramètres de présentation : zoom, famille de police, contrastes des sites web.
1. Activer les options d’accessibilité une à une et vérifier qu’elles s’appliquent sur la page. Par exemple, dans Firefox, activer l’option « Personnalisé » dans les « Contrastes de couleurs », choisir des couleurs identifiables et vérifier qu’elles s’appliquent sur la page. 
1. Rechercher dans le code (élément `<meta name="viewport">`), l’absence de déclaration visant à interdire ou restreindre le zoom : 
	- `user-scalable=no` ; 
	- `maximum-scale` avec une valeur réduite.
1. Rechercher dans les styles qui s’appliquent sur la page, les propriétés CSS qui peuvent bloquer l’application des préférences des utilisateurs : 
	- `forced-color-adjust` avec la valeur `none` ;
	- `color-scheme` avec la valeur `only light` ou `only dark`.
1. Rechercher dans les styles, l’absence de déclarations bloquantes dans les <em lang="en">media queries</em> liées aux préférences utilisateurs :
	- `prefers-color-scheme` ; 
	- `prefers-contrast` ;
	- `prefers-reduced-motion` ;
	- `prefers-reduced-transparency` ;
	- `forced-colors` ;
1. Si c’est le cas, **le critère est validé**.

Source : <a href="https://www.w3.org/TR/mediaqueries-5/#mf-user-preferences" lang="en">User Preference Media Features (Media Queries Level 5)</a>
